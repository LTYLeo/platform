Getting Started with TAI API

Welcome to the TAI Developer Platform! This guide will help you get started with our API and integrate TAI models into your applications.

Authentication

All API requests require authentication using your API key. You can find your API keys in the Dashboard. 

import tai

# Initialize the client with your API key
client = tai.Client(api_key="YOUR_API_KEY")

Making Your First Request

Here's a simple example of how to use the chat completions endpoint: 

response = client.chat.completions.create(
  model="gtc-2.5-mini",
  messages=[
    {"role": "system", "content": "You are a helpful assistant."},
    {"role": "user", "content": "Hello, how are you?"}
  ]
)

print(response.choices[0].message.content)

Available Models

Pass one of the model IDs below as the model parameter. GTC-2.5 mini and TFMF are live; the companion models are still in LoRA training.

Model Description Best For Status
GTC-2.5 mini
gtc-2.5-mini 		Lightweight 64M base model Basic chat, knowledge Q&A, simple text generation, edge deployment Live
TFMF
tfmf 		General foundation model on Qwen 3.5-4B (INT8) General chat, instruction following, vertical-domain LoRA adaptation Live
Giggle
giggle 		General companion model (TFMF + LoRA) Casual chat, playful interaction, everyday listening In training

sweetie 		Companion model (TFMF + LoRA) Emotional support, relationships, everyday sharing In training

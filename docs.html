Getting Started with the TAI API

The TAI Assistant API is our own shape — not a clone of anyone else's. It gives you assistants, persistent threads, one-off chat, and streaming, authenticated with an API key.

Authentication

Create a key in the Dashboard, then send it as a bearer token. Keys are shown in full only once, when you create them. 

curl https://YOUR_API_HOST/api/v1/models \
  -H "Authorization: Bearer sk-tai-..."

Your First Request

Install the SDK and make a stateless call:

pip install tai-sdk
from tai_sdk import TAI

client = TAI(api_key="sk-tai-...")   # base URL is auto-discovered

reply = client.chat.create(
    model="tfmf",
    messages=[{"role": "user", "content": "Hello!"}],
)

print(reply.output.content)
print(reply.usage.input_tokens, reply.usage.output_tokens, reply.usage.cost_cny)

Prefer raw HTTP? POST /api/v1/chat takes the same fields as JSON and returns the same shape.

Streaming

Pass stream=True and you get server-sent events: message.start, then message.delta per fragment, then message.done carrying the usage. 

from tai_sdk.types import MessageDelta, MessageDone

for event in client.chat.stream(
    model="tfmf",
    messages=[{"role": "user", "content": "Count to five."}],
):
    if isinstance(event, MessageDelta):
        print(event.delta, end="", flush=True)
    elif isinstance(event, MessageDone):
        print("\n", event.usage.output_tokens, "tokens")

Assistants & Threads

An assistant stores a model plus system instructions. A thread stores the conversation, so you never resend history. 

assistant = client.assistants.create(
    name="Tutor",
    model="tfmf",
    instructions="You are a patient tutor. Answer briefly.",
)

thread = client.threads.create(assistant_id=assistant.id)

exchange = client.threads.messages.create(
    thread.id,
    content="Explain LoRA in two sentences.",
)
print(exchange.assistant_message.content)

Errors & Rate Limits

Every failure returns a stable code alongside a human-readable message, and the SDK turns it into a typed exception:

  • 401 invalid_api_key → AuthenticationError
  • 404 model_not_found → ModelNotFoundError
  • 409 model_not_available → ModelNotAvailableError (still training)
  • 422 invalid_request → BadRequestError

Per-key rate limits and balance enforcement are not switched on yet — they are the next thing we are building. Treat the platform as a preview.
